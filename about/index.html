白天写前端，和布局、状态、构建工具打交道；晚上读点书，或者出门走一走。这个博客用来存放那些不适合发在社交媒体上的东西——不够短，不够快，也不够确定。

  • 写界面，也写一点 Python 小工具
  • 读得比较杂：设计、随笔、小说、技术书
  • 喜欢在城市里没有目的地走路
  • 正在练习把一件事说清楚

这个站#

「拾光集」始于 2024 年，2026 年搬到这里。名字取自“拾起微光”的意思：日常里那些很小的、容易被忽略的时刻，值得被记下来。

这里没有评论区，没有广告，也没有第三方统计。你读了什么、停留多久，都不会被记录。想追更的话，RSS 是最可靠的方式。

排版与实现#

整站由一个一千多行的 Python 脚本生成，只使用标准库，不依赖 Node、npm 或任何构建框架。Markdown 在本地编译成静态 HTML，推送到 GitHub 后由 GitHub Pages 托管。

  • 字体：标题用系统宋体（思源宋体 / 宋体 SC），正文用系统无衬线，代码用等宽字体。没有网络字体，所以不闪、也不慢。
  • 配色：底色取宣纸的暖白，强调色取朱砂。深色模式是一套独立的颜色，而不是简单反色。
  • 交互：主题切换、全文搜索、目录高亮、代码复制，全部用原生 JavaScript 写成，没有框架。
  • 内容：文章是纯文本 Markdown，图片放在 assets/img/，二十年后大概还能读。

如果你也想搭一个类似的站点，构建脚本和模板都在仓库里，拿去改就好。
